# 🏙️ Smart City Network Simulation and Congestion Analysis

## 📌 Project Overview

The **Smart City Network Simulation and Congestion Analysis** project focuses on simulating network communication in a smart city environment. Smart cities contain various connected devices such as traffic signals, CCTV cameras, environmental sensors, street lights, and emergency services.

These devices continuously exchange data over a network. When multiple devices transmit data simultaneously, network congestion, buffer overflow, packet loss, and reduced throughput may occur.

This project uses **Java** to simulate network traffic and analyze performance, and **Cisco Packet Tracer** to design and simulate the smart city network topology. A web-based dashboard displays the simulation results.

## 🎯 Objectives

- Design a smart city network topology.
- Simulate network traffic and congestion.
- Generate packets based on traffic congestion levels.
- Implement buffer management.
- Implement the Leaky Bucket algorithm.
- Analyze packet transmission and packet loss.
- Calculate throughput, data rate, and drop rate.
- Compare TCP and UDP protocols.
- Display simulation results through a web dashboard.
